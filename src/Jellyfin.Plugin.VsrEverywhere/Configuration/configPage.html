Experimental NVIDIA enhancements (Windows)

VSR cache management

Rejects new enhanced streams when the plugin-owned cache is over budget. In full-playback mode, an active long movie may exceed the budget; use rolling mode to bound growth.
Idle sessions release their cached segments.
Memory and rolling disk caches retain this rewind window, within the available budget.

Processing and delivery resolution

VSR image enhancement

Standard modes remove compression artifacts; high-bitrate modes preserve more texture in cleaner sources. Modes depend on your installed NVIDIA VFX SDK.
Default 0.75. Try 0.5–0.75 to avoid waxy textures.

HEVC NVENC encoding

0 disables lookahead; 10–20 can help complex scenes but raises GPU load.
0 disables CQ and retains bitrate-based encoding. When enabled, lower values mean higher quality; bitrate and maxrate still apply.

Changes apply to new playback sessions. More demanding settings can increase processing load.

Unsupported sources use standard Jellyfin playback.
